# Research artifacts

This directory contains three independently authored notebook collections that generate channel descriptions:

- `Jules/1.Description-Topology-Analysis.ipynb`
- `codex/semantic_description_pointcloud_alignment.ipynb`
- `copilot/1.Channel-Descriptions.ipynb`

## Merged channel-description object

Use `merge_drive_descriptions.py` from a Colab runtime after mounting Google Drive to merge the descriptions generated by those notebooks into one channel-indexed JSON object:

```bash
python research/merge_drive_descriptions.py
```

By default, the script reads the Drive artifacts written by each notebook:

| Source subdirectory | Drive artifact read by the merge script |
| --- | --- |
| `Jules` | `/content/drive/MyDrive/research/channel_descriptions_and_segments.json` |
| `codex` | `/content/drive/MyDrive/Graphiko/research/semantic_description_pointcloud_alignment/descriptions/by_channel/` |
| `copilot` | `/content/drive/MyDrive/Research/channel_descriptions/latest/all_channels.json` |

The merged object is written to:

```text
/content/drive/MyDrive/Graphiko/research/merged_channel_descriptions/latest/all_channel_descriptions_by_source.json
```

The output shape is:

```json
{
  "schema_name": "graphiko.research.merged_channel_descriptions_by_source",
  "schema_version": "1.0.0",
  "sources": {
    "Jules": "/content/drive/MyDrive/research/channel_descriptions_and_segments.json",
    "codex": "/content/drive/MyDrive/Graphiko/research/semantic_description_pointcloud_alignment/descriptions/by_channel",
    "copilot": "/content/drive/MyDrive/Research/channel_descriptions/latest/all_channels.json"
  },
  "channels": {
    "Example Channel": {
      "Jules": "Jules: ...",
      "codex": "codex: ...",
      "copilot": "copilot: ..."
    }
  }
}
```

By default, only channels present in all three source artifacts are included so every channel has three comparable descriptions. To include channels that are missing one or more source descriptions, run:

```bash
python research/merge_drive_descriptions.py --include-partial-channels
```

Use repeated `--source NAME=/path/to/artifact` arguments to override any default Drive path, and use `--output /path/to/output.json` to write the merged object somewhere else.
