# Graphiko Admin Web App

A React, TypeScript, and Bulma admin dashboard for operating the Graphiko analytics workflow.

## Scripts

```bash
npm install
npm run dev
npm run build
npm run lint
```

## Netlify

This app is ready for Netlify as a separate site. In Netlify, set the base directory to `admin-webapp`; the included `netlify.toml` builds the Vite app and publishes `dist`.

A live deploy was not attempted from this environment because no Netlify authentication token or linked site configuration is available.
